# Notes

Numbered LaTeX write-ups. Sources are in `tex/` (shared macros in `tex/macros.tex`, figures in
`tex/figs/`); the compiled PDFs are committed next to this file so they can be read on GitHub.
Notes keep their numbers for good, so cite them by number. To start a note, take the next number,
push a stub at once to reserve it, and add a line below.
